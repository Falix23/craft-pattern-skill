这些示例展示插画、彩色线稿和已有像素素材的转换效果。新的东方明珠采用清晰线稿输入，轮廓和大色块便于采样。自动生成并不等于人工精修，仍需检查五官与细线等关键位置。各色统计只对应本项目实际生成的格子，不复用原帖的材料清单；色号均为通用 RGB 参考，不冒称 MARD 等品牌官方色号。

`inputs/` 保存本次选定的图片：东方明珠的完整素材另存为 `tower-original.webp`，单体裁切另存为 `tower.webp`；布布一二完整拥抱原图为 `bubu.webp`，直接使用原图，不裁切或拼版。`cases.json` 保存参数、来源和署名；`summary.json` 保存实际生成统计和各文件的相对路径，另记录输入文件 SHA-256。`patterns/` 为本项目生成的 JSON、SVG 和材料 CSV，`../../assets/showcase/` 为展示及符号制作图。各文件按上述素材权利说明使用，代码许可证不授予素材、人物肖像或角色的额外使用权。

在已安装 Pillow 与 Node.js 的环境中重建：

```sh
python scripts/build_showcase.py
```

脚本只读取已选定的本地输入，使用临时目录和 `--no-archive` 生成，不访问账号、不自动搜集笔记、不读写用户案例库。完整选图原件及其可见署名保存在 `inputs/`，单体裁切和来源信息记录在 `cases.json`。选定参数与结果可逐一对照 `cases.json`、`summary.json` 和图纸 JSON。

## 低分辨率对比

使用上述同一批输入，另生成最长边 32/48/64 格三档。每个主题沿用其选定方案的中档颜色区分度、颜色数量上限、背景与清理设置，只改变尺寸，不更换素材。`low-resolution-summary.json` 记录输入 SHA-256、处理设置及 12 个方案的尺寸、色数和用豆数；`low-resolution/` 保存 JSON / SVG / CSV，`../../assets/showcase/low-resolution/` 保存网格预览与符号制作图。`../../assets/showcase/low-resolution-comparison.png` 为同尺度的无辅助线预览，便于观察形状损失。运行 `python scripts/build_showcase.py` 会同时重建这组低分辨率结果。
低格数版本使用局部填色支持、紧凑暗线保留、Oklab 最近色映射与色相点缀保护重新生成；尺寸、源图、背景、清理档位与颜色数量上限沿用原设置，算法更新可能改变实际色数。红球、眼睛和嘴线取自输入采样，无语义重绘或人工逐格补画。

本轮采用 6× 子采样、黑帽形态学与 Shi–Tomasi 结构张量响应辅助保留短线，并在近色合并、色板预算、映射及清理中共同保护明显不同的色相；布布一二两侧腮红分别从原图采样为粉色与黄色。尺寸与配色上限未提高，也未手工逐格修补示例。

布布一二的清晰分区版本先按稳定源色区采样，再按短线中心线与弯折进行有界的像素化重建。32/48/64 格固定中档配色与最多 8 色，实际均为 5 色；对比图下排只放大同一位置，不改变格子数据。短线可轻微放大并在一格范围内对齐，封闭舌头、粉色和黄色腮红保留源色。`bubu-expression-comparison.png` 由 `build_showcase.py` 同步重建，未人工逐格补画。
