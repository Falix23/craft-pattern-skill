这些示例展示插画、实物照片和已有像素素材的转换效果。自动生成并不等于人工精修；实物照片中的豆孔、阴影和透视会影响转换，不能把重采样结果当作原作者图纸的准确复原。各色统计只对应本项目实际生成的格子，不复用原帖的材料清单；色号均为通用 RGB 参考，不冒称 MARD 等品牌官方色号。

`inputs/` 保存本次选定的图片，`cases.json` 保存参数、来源和署名；`summary.json` 保存实际生成统计和各文件的相对路径，另记录输入文件 SHA-256。`patterns/` 为本项目生成的 JSON、SVG 和材料 CSV，`../../assets/showcase/` 为展示及符号制作图。各文件按上述素材权利说明使用，代码许可证不授予素材、人物肖像或角色的额外使用权。

在已安装 Pillow 与 Node.js 的环境中重建：

```sh
python scripts/build_showcase.py
```

脚本只读取已选定的本地输入，使用临时目录和 `--no-archive` 生成，不访问账号、不自动搜集笔记、不读写用户案例库。图片中的可见平台水印保留在参考素材中。选定参数与结果可逐一对照 `cases.json`、`summary.json` 和图纸 JSON。
