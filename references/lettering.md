# 带字图片的默认分区处理

对所有带文字的输入默认执行图文分区检查，包括队标、品牌标志、名字、编号、海报、招牌和照片里的文字，不限于BLG或英文小字，也不要求用户先说“文字保清”。这是 Agent 的默认工作流；底层脚本不会自行 OCR 或自动划出文字框。

## 默认决策

- 先逐字核对内容，定位文字区与图案区，检查目标格数能否表达笔画、字间空白和文字颜色。图案按原流程采样；文字单独决定保留原字形或按点阵字重排，不把文字笔画当作杂色点清除。
- 原字形在指定格数下已清楚时直接保留。需要提高可读性、内容已确认且字符集受支持时，优先用下述独立重排，并说明对字形、字号及排版的修改；用户明确要求保留品牌字体、书法或原排版时，不用通用字体替代。
- 中文、其他语种、小写或特殊符号也按文字区独立检查。当前重排器不支持的内容保留原字形并核查；若仍不可读，如实说明能力或格数限制，可另附更高格数方案等备选，不能强行套用英文字库、悄悄大写化、猜写或删字。
- 无法确认文字内容时只针对缺失内容向用户核对，仍可先处理不依赖该答案的图案区。尺寸或色数受限时保留用户指定的约束，不通过暗中放大画布、增加材料或挤掉主图来制造“清晰”效果。
- 合成后逐字检查拼写、顺序、字距、换行、字色与背景对比，确认文字和主图没有互相覆盖；每个尺寸方案都要重新检查，不能只看放大预览。

## 工作方式

1. 图案照原流程采样、配色与清理。
2. 只清除指定的旧文字区域，使用**现有色板**把文字按点阵字重排；这一步之后不再做杂色清理。区域外的格子及色板保持逐项一致，不新增材料。
3. 更新图纸、符号、各色用量和留空统计。分区配置写入图纸 JSON 的 `text_layers`，manifest 中的 `lettering` 给出实际换行、字形和占位。

目前字形为自绘 `compact-5`：5格高、按字母分配1～5格宽，字母间至少留1格，词间留2格；只支持大写 `A–Z`、数字、空格、换行以及 `- . /`。优先单行，空间不足按完整单词换行，绝不压缩、截字或跨格绘制。仍放不下时直接报错，应提高格数、扩大已预留的文字区、明确分行或减少内容。

例如 `BILIBILI GAMING` 单行最少48格宽、5格高；32格画布可在11格高的区域排为两行。这里已改变原来的字宽和字号，不是原品牌字体的自动恢复。不能把重排版混入“只做原图采样”的竞品对比，或宣称它在相同处理条件下自然识别了文字。

## 显式配置

创建 `lettering.json`，数组最多4项：

```json
[
  {
    "text": "BILIBILI GAMING",
    "box": [0, 0.65, 1, 0.35],
    "foreground": "#2ACDEB",
    "background": "#FFFFFF",
    "layout": "auto"
  }
]
```

- `box` 为**最终画布**的比例 `[x, y, width, height]`，范围0～1；每个边界按实际格数取整。它不是原图像素坐标。先确保预留区没有眼睛、主标志等图案。
- `clear_box` 可选，默认同 `box`，用于清除旧文字；绘制区与清除区都会被填成指定背景。多个文字层的这些区域不能互相覆盖。
- `foreground` 为目标 RGB 参考色，默认黑色，映射到已有色板；`background` 默认 `null`（真实留空），也可指定 RGB 参考色。选定色板无法区分文字和背景时拒绝输出。
- `layout` 为 `auto` 或 `single`；后者不允许自动换行。`text` 最多80字符，支持显式换行，不接受空白行。

```sh
python scripts/generate.py /绝对路径/logo.png --width 64 --background keep --lettering lettering.json
```

与 `--plans`、`--compare` 可组合；某方案需单独配置时，在该方案项中提供 `text_layers` 数组，空数组禁用该方案的文字重排。未传入配置时原有出图行为不变。

交付时说明文字内容、单行或换行、实际格数与用色，查看 PNG 中的字形和间隔。发生字形或排版调整时，可附局部前后对照；用户指定只交付一张时保持其数量要求，并用文字说明差异。只有图纸文件能准确恢复排字结果，源图片本身不记录该配置。案例库保存 `text_layers`；后续改尺寸应从该字段恢复配置再调用 `--lettering`。编辑器导入保留已生成格子和配置，但页面重新生成图片暂不自动重排文字；网页也没有自动文字检测开关。
